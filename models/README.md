# Models Directory

Place your GGUF models here or symlink them.

Suggested structure:
- `models/qwen2.5-7b-instruct-q4_k_m.gguf` (Utility)
- `models/qwen3-coder-30b-q4_k_m.gguf` (Coder)
- `models/llama-70b-instruct-q4_k_m.gguf` (Thinker)

If you have models stored mainly on host, you can mount them into the toolbox at `/models`.
